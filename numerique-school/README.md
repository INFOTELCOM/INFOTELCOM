# Numerique School

Projet SaaS de gestion scolaire — Collège & Lycée.

Le projet contient :
- site vitrine premium ;
- application SaaS V1 ;
- gestion élèves / inscriptions / classes ;
- notes & évaluations avec verrouillage ;
- bulletins & rapports ;
- statistiques ;
- schéma de données Supabase ;
- architecture V2 prévue.

## Démarrage local

```bash
npm install
npm run dev
```

Application : `/#app`

Le dépôt de développement complet est livré dans l'archive de travail associée à ce projet.
